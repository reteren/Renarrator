a really funny program, honestly i have no idea why i made this nonsense.

what can be said about it:

you can create triggers and add sounds and keywords to them, and if you type those words on your keyboard, a sound plays. the max delay between letters is 2 seconds — if you're typing a word and pause for 2 seconds, the word won't fire. you can add as many keywords as you want, you just write them separated by a comma "," and of course you can use digits and spaces inside the words.

besides different keywords, you can also add as many sounds as you want to a single trigger, and if you add at least 2 sounds, you can set the drop chance for each sound when the trigger fires.

basically that's it. the program is funny, so i don't know who could ever need it — unless, of course, you want to use it to play yourself a sound every time you type Ni...... just so you know, i meant nitroglycerin))
